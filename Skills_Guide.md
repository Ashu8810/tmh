# Comprehensive Guide to Antigravity Skills

## What are Skills?
Skills are specialized instruction sets and tools that I (Antigravity) can use to help you with specific, complex tasks. Instead of just relying on general knowledge, skills provide me with expert-level guidelines, best practices, and automated scripts tailored to specific domains.

## How to Use Skills in Prompts
*   **Implicitly:** Simply ask me to perform a task (e.g., "Set up a new React component"). I will automatically find and use the relevant skill.
*   **Explicitly:** Mention the skill by name (e.g., "Use the `frontend-design` skill to design a landing page").

*   **`frontend-design`**: Acts as a frontend designer-engineer. Focuses on premium, modern web aesthetics (glassmorphism, micro-animations, perfect typography, responsive mobile-first layouts).
